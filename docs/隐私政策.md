# 极速连点器隐私政策

更新日期：2026年8月15日
生效日期：2026年8月15日

## 1. 概述
极速连点器（以下简称"本应用"）尊重并保护用户隐私。为实现自动连点功能，本应用需要在系统设置中获取悬浮窗、无障碍服务和通知权限，但不会收集、上传或向第三方提供任何个人信息。

## 2. 数据处理方式
本应用的所有配置数据（圆点坐标、点击间隔、点击次数、方案、统计数字）均保存在设备本地的应用数据目录中。卸载应用后，这些数据会一并清除。本应用不接入广告、统计、推送或第三方分析 SDK，也不具备联网上传能力。

## 3. 权限说明
- 悬浮窗：用于显示可拖拽的圆点定位界面与悬浮控制球。
- 无障碍服务：用于按用户自行设置的圆点和参数，在其他应用界面执行点击、长按、滑动手势。
- 通知：用于展示连点运行状态并提供快捷停止入口。
- 前台服务：用于保持悬浮控制球稳定运行，方便用户快速开始或停止。

## 4. 数据安全
本应用不收集敏感信息，不使用网络传输数据，数据仅保存在本地。请从官方或正规应用市场渠道下载，避免使用被篡改的安装包。

## 5. 儿童隐私
本应用不面向儿童收集任何个人信息，也不提供针对儿童的定向内容。

## 6. 用户控制
用户可以随时在系统设置中关闭悬浮窗、通知或无障碍权限，也可以停止前台服务或卸载本应用。关闭无障碍权限后，自动连点功能将立即无法执行。

## 7. 政策更新
如隐私政策发生变更，我们会在本页面更新版本及日期。继续使用本应用即表示接受更新后的政策。
