# 应用简介文案

## 50 字版本
拖拽圆点即可设置多位置自动连点，支持顺序/随机点击、长按、滑动和多点同时，悬浮球一键开始停止。

## 200 字版本
极速连点器是一款本地运行的效率工具，不需要输入屏幕坐标，直接拖拽悬浮圆点即可完成多点定位。支持多圆点顺序点击、随机点击、长按、滑动和多点同时手势，可自定义点击间隔、次数与随机抖动。内置快捷模板、方案保存、模板图鉴与图文教程，悬浮控制球可在其他应用中使用：上滑开始、下滑停止、左侧退出连点器。所有配置与统计仅保存在手机本地，不联网、不收集个人信息，卸载即清除。

## 500 字版本
极速连点器是面向个人重复操作场景的桌面型效率工具，专为"多个固定位置、按固定顺序反复点击"设计。启动后无需记忆或输入任何 x/y 坐标，进入"设置圆点"即可在屏幕上直接拖拽出多个彩色圆点，圆点顺序即为点击顺序；长按圆点可按像素级微调位置，拖到屏幕边缘可快速调整顺序。应用支持普通点击、长按、滑动和多点同时四种手势，以及顺序、随机、单点三种模式，可设置间隔、随机抖动和点击次数，也支持无限循环。

为了快速上手，内置了多点连击、签到点赞、日常任务、挂机循环、全屏环绕等多套快捷模板，并配有模板图鉴与 20 页图文教程。方案库可以把圆点、参数和手势组合保存下来，一键切换多套任务。

在操作其他应用时，悬浮控制球提供快捷控制：上滑开始连点、下滑停止连点，左侧按钮直接退出连点器。应用不包含广告和联网功能，不收集用户信息，所有点击配置与统计都保存在设备本地；用户可在系统设置中随时关闭悬浮窗、通知和无障碍权限。

适用场景：游戏日常重复操作辅助、表单填写、应用内重复按钮点击等个人效率场景。
