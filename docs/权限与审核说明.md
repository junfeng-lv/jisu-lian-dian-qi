# 权限说明与审核风险

## 权限用途
- 悬浮窗（SYSTEM_ALERT_WINDOW）
  用途：圆点定位、悬浮控制球显示。
  说明：不遮挡关键操作，用户可拖动到屏幕边缘。

- 无障碍服务（AccessibilityService）
  用途：根据用户设置的圆点和参数模拟点击、长按、滑动手势。
  说明：仅执行用户主动保存和启动的任务，不做后台监听或数据采集。

- 通知（POST_NOTIFICATIONS）
  用途：展示连点运行状态，提供一键停止。

- 前台服务（FOREGROUND_SERVICE）
  用途：保持悬浮控制球运行，方便开始/停止。

## 审核风险提示
自动点击类工具在国内部分市场可能被归入高风险类别，常见驳回原因包括：被判定为外挂脚本、抢购工具、游戏作弊辅助或危害平台规则。建议：

1. 分类选择"系统工具 / 效率工具"。
2. 简介描述强调"个人重复操作自动化"，避免出现"抢购、抢单、游戏加速、云手机脚本、作弊"等词。
3. 提前准备操作演示视频，说明仅用于普通应用中的重复点击场景。
4. 如被驳回，按市场提示补充使用场景说明、隐私政策链接、软著或免责声明。
5. 部分市场要求个人开发者提供《计算机软件著作权登记证书》，建议提前办理。
